## Verification Script (Step-by-Step, on device)

1. `./run-dev.sh` → Play → Random → Send → status shows "Searching for
   opponent…"
2. Match on lichess.org (open the seek in a browser/second account) → the app
   opens ChessGameScreen with the matched game within a few seconds
3. Back during search → seek is gone from lichess.org (connection drop cancels)
4. Game over vs the random opponent → Rematch → new seek starts
